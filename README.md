# SoundOS

Модульный конструктор синтезаторов в браузере: собираете патч из нод (генераторы + обработка сигнала), нажимаете **Generate** — и получаете полноценно играющий полифонический синтезатор с виртуальной клавиатурой.

Название рабочее — переименовать проект тривиально (заголовок в `index.html`, `<title>`, брендинг в `#toolbar .brand`).

## Запуск

Нужен локальный HTTP-сервер (ES-модули и AudioWorklet не работают через `file://`):

```bash
cd soundos
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Как это устроено

- **`js/nodeLibrary.js`** — систематизированная база нод. Каждая нода описывает свои порты (входы/выходы), параметры и фабрику `build(ctx)`, которая создаёт реальный Web Audio граф с единым контрактом (`inputs`, `audioParams`, `output`, `setParam`, `dispose`, опционально `applyNote`/`gateOn`/`gateOff`). Добавить новую ноду — значит дописать один объект в этот файл; меню и движок подхватят её автоматически.
- **Генераторы**: Oscillator, LFO, Noise, Envelope (ADSR как источник CV-сигнала — как в модульных синтезаторах, а не встроенный в VCA).
- **Обработка**: Filter, Amp/VCA, Mixer, Delay, Distortion, Reverb, **Math**, Output.
- **`js/canvas.js`** — визуальный редактор: ноды — компактные HTML-блоки на панорамируемом холсте, связи — SVG-кривые. Перетаскивание нод, соединение портов драгом, удаление связи кликом по проводу.
- **`js/menu.js`** — систематизированное меню нод (генераторы/обработка, поиск). На десктопе выбор ноды открывает сетку — можно явно выбрать ряд и столбец размещения; на мобильном нода ставится автоматически.
- **`js/audio/engine.js`** — компилирует визуальный патч в реальный полифонический движок: каждый голос — независимая копия всего графа, голоса делят общую мастер-шину. Проигрывание ноты — клонирование, а не пересборка графа на лету.
- **`js/audio/worklets/mathProcessor.js`** — Math-нода через AudioWorklet: родной Web Audio умеет только *суммировать* сигналы, приходящие в параметр, поэтому для `multiply`/`min`/`max` («ИЛИ»-подобное комбинирование) нужна честная поэсэмпловая математика.
- **`js/keyboard.js`** — компьютерная клавиатура как пианино (A W S E D F T G Y H U J K, Z/X — смена октавы) + сенсорная клавиатура на экране.

## Философия патчинга

Любой выход можно подключить к любому входу — как аудио-входу другой ноды, так и напрямую в параметр (модуляция). Ограничений по типам сигналов нет: например, осциллятор можно завести прямо в частоту другого осциллятора (FM), а LFO — в Math-ноду, где его сигнал скомбинируется с другим сигналом (сложение/вычитание/умножение/min/max/среднее) перед тем, как отправиться модулировать частоту фильтра.

## Известные упрощения (MVP)

- Полифония реализована через клонирование всего графа на голос — значит эффекты (реверб, дилей) тоже дублируются на голос, а не общие. Для несложных патчей это не критично.
- Нет зума холста — только панорамирование (клик по пустому месту + драг) и большая рабочая область.
- Voice stealing при нехватке голосов — самая простая стратегия (не приоритет по громкости/времени релиза).
- Export/Import — только JSON-патч (структура графа), не автономный HTML-плеер.

## Дальнейшие идеи

- Экспорт патча в самостоятельный HTML-файл, который проигрывает пресет без редактора.
- Zoom холста, привязка к сетке при обычном перетаскивании.
- Сэмплер / MIDI-вход с реального устройства.
- Общая (не по-голосовая) шина для эффектов через отдельный тип "master insert" ноды.
